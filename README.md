# 🌿 الجليل – متجر الطب البديل والمنتجات الطبيعية

متجر إلكتروني عربي كامل (موقع + تطبيق قابل للتثبيت على الموبايل) لبيع الأعشاب الطبية والزيوت والكريمات والصوابين الطبيعية، مع مستشار ذكي بالذكاء الاصطناعي ولوحة تحكم كاملة.

## المزايا

**واجهة المتجر**
- سلايدر رئيسي متحرك (Ken Burns + حركة نصوص + سحب باللمس) – الشرائح تُدار من لوحة التحكم.
- أقسام، شبكة منتجات مع فلاتر (قسم، سعر، خصم، توفر) وترتيب، بحث فوري.
- صفحة منتج: معرض صور مع تكبير، فوائد، طريقة الاستعمال، مكونات، تحذيرات، تقييمات الزبائن، منتجات مشابهة.
- سلة جانبية محفوظة، شريط تقدم للتوصيل المجاني، مفضلة.
- إتمام الطلب: الاسم، العائلة، البلدة، العنوان، الهاتف (مع تحقق)، **تحديد الموقع GPS** أو رابط خرائط، ملاحظات، كوبون خصم.
- **الدفع عند الاستلام فقط** وبعملة الشيكل ₪. الخصومات بالنسبة المئوية تُحسب تلقائياً **على الخادم** (لا يمكن التلاعب بالأسعار).
- تتبع الطلب برقم الطلب ورقم الهاتف.
- إعلان منبثق (Popup) مع كود خصم، شريط إعلانات متحرك، **وضع ليلي**، زر واتساب عائم.
- تطبيق قابل للتثبيت (PWA): من المتصفح على الموبايل ← "إضافة إلى الشاشة الرئيسية".

**المستشار الذكي "حكيم الجليل"**
- محادثة موسّعة مخصصة للأعشاب والطب البديل فقط (يرفض المواضيع الأخرى بلطف).
- يسأل عن الحمل، الأمراض المزمنة، والأدوية قبل اقتراح الخلطة، ويتجنب الأعشاب الخطرة، ويوجّه للطبيب عند الأعراض الخطيرة.
- يعطي الخلطة بالكميات وطريقة التحضير والمدة والتحذيرات، ويقترح منتجات من المتجر.
- في النهاية يسأل الزبون إن كان يريد الخلطة ← زر **"موافق"** ← يعبّي الاسم والعائلة والبلدة والهاتف ← **يصل الطلب للوحة التحكم** مع المحادثة كاملة.

**لوحة التحكم** (`/admin`)
- الطلبات: كل التفاصيل، الموقع على الخريطة، الأسعار والخصومات، تغيير الحالة، واتساب/اتصال بالزبون، طباعة، تصدير Excel، **تنبيه صوتي وإشعار عند وصول طلب جديد**.
- طلبات الخلطات من المستشار الذكي.
- المنتجات (صور متعددة، سعر، خصم %، مخزون…)، الأقسام، التقييمات، الكوبونات.
- السلايدر، الإعلان المنبثق، ترتيب أقسام الصفحة الرئيسية، كل النصوص.
- الاسم والشعار: مكان الاسم (يمين/وسط/يسار)، حجم اللوجو والاسم، الخطوط، الألوان، الوضع الليلي، CSS مخصص.
- أرقام واتساب والهاتف والبريد ومواقع التواصل، رسوم الشحن والتوصيل المجاني.
- المستخدمون والصلاحيات (مالك، مدير، محرر، موظف طلبات)، نسخ احتياطي واستعادة، تغيير كلمة المرور.

**إضافات**
- حسابات زبائن اختيارية + صفحة "طلباتي" + حملات وعروض للمشتركين.
- أحجام متعددة لنفس المنتج (لكل حجم سعر ومخزون).
- مناطق توصيل بأسعار مختلفة.
- تنبيهات فورية على تيليجرام مع كل طلب (لوحة التحكم ← تنبيهات تيليجرام، فيها الخطوات).
- QR كود جاهز للطباعة.
- تقارير شهرية (مبيعات، منتجات، بلدات، مناطق) مع تصدير Excel.
- مقالات ونصائح مع صفحات قابلة للأرشفة في جوجل (`/blog/...`, `/product/...`, `sitemap.xml`)، وكتابة مسودات بالذكاء الاصطناعي.

## التشغيل على الكمبيوتر

يحتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
npm start
```

ثم افتح: `http://localhost:3000` (المتجر) و `http://localhost:3000/admin` (لوحة التحكم).

## تفعيل المستشار الذكي

المستشار يعمل عبر Claude من Anthropic:
1. أنشئ حساباً على [console.anthropic.com](https://console.anthropic.com) واحصل على مفتاح API.
2. ضع المفتاح في متغير البيئة `ANTHROPIC_API_KEY` (في إعدادات الاستضافة، أو قبل التشغيل محلياً):
   ```bash
   ANTHROPIC_API_KEY=sk-ant-... npm start
   ```
3. بدون المفتاح يعمل المتجر بشكل طبيعي ويختفي المستشار من الواجهة.

متغيرات اختيارية: `CLAUDE_MODEL` (الافتراضي `claude-opus-5-5`)، `CLAUDE_EFFORT` (الافتراضي `low` لردود سريعة)، `PORT`، `DATA_DIR`، `SESSION_SECRET`.

## النشر على الإنترنت

كل بيانات المتجر (المنتجات، الطلبات، الإعدادات، الصور المرفوعة) محفوظة في مجلد `data/`، لذلك تحتاج استضافة فيها **قرص دائم (Persistent Disk / Volume)** حتى لا تضيع البيانات عند إعادة التشغيل.

**على Render.com (الأسهل – بدون أي برمجة):**
المشروع فيه ملف `render.yaml` يجهّز كل شيء تلقائياً (الخادم + قرص لحفظ البيانات).
1. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
2. **New +** ← **Blueprint** ← اختر المستودع `alkarnak` والفرع الذي فيه الكود.
3. سيطلب قيمة `ANTHROPIC_API_KEY` (مفتاح المستشار الذكي) – ضعه الآن أو اتركه فارغاً وأضفه لاحقاً.
4. اضغط **Apply** وانتظر 3-5 دقائق. رابط الموقع يظهر أعلى الصفحة (مثل `https://aljalil.onrender.com`).
5. التكلفة تقريباً 7$ شهرياً للخادم + أقل من 1$ للقرص.
6. لربط اسم نطاق خاص: Settings ← Custom Domains.

يعمل أيضاً على Railway (مع Volume) أو أي خادم VPS عليه Node.js.

## هيكل المشروع

```
server.js            الخادم وكل واجهات البرمجة (عامة + إدارة)
lib/store.js         تخزين البيانات في data/db.json
lib/seed.js          البيانات الأولية: منتجات، أقسام، إعدادات
lib/ai.js            المستشار الذكي (Claude API)
lib/art.js           مولّد صور المنتجات التجريبية
public/index.html    واجهة المتجر
public/js/store.js   منطق المتجر
public/css/store.css تصميم المتجر
public/admin/        لوحة التحكم
```

> صور المنتجات الحالية رسومات تجريبية. استبدلها بصور منتجاتكم الحقيقية من لوحة التحكم ← المنتجات.
